Implement `TTLCache` in `cache.py` with this API: `TTLCache(capacity, ttl_seconds, clock=None)`, `set(key, value)`, `get(key, default=None)`, `delete(key)`, `key in cache`, and `len(cache)`. Capacity must be a positive integer and TTL a positive number; reject invalid values with `ValueError`. Use `time.monotonic` by default and allow an injected zero-argument clock for deterministic use. Entries expire when `now >= expires_at`; reads update LRU recency but do not extend TTL. Setting an existing key replaces its value and refreshes its TTL and recency. Evict the least recently used unexpired entry when capacity is exceeded. Membership and length must ignore expired entries, and `delete` returns whether a live entry existed. Keep the API and filename unchanged.
